# second time in the ci corpus sweep with every build on the per-module path

# The files scripts/corpus_per_module_slice_select.sh prints (its header states
# the rule: multi-module programs, `blink test` runs, and tests of the per-module
# build, emit and unit reuse, and the obj cache). Refresh with:
#   scripts/corpus_per_module_slice_select.sh
# `task ci` fails when the rule and this list disagree
# (scripts/corpus_per_module_slice_drift.sh). A file picked by hand carries
# "# manual" after its path. A file the rule picks that the slice leaves
# out gets a line "# exclude <path>: <why>".
