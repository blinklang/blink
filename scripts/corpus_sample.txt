# The full corpus is 1671 files and takes about six minutes, so the branch
# gate does not run it. A gate with no corpus stage can green a slice that
# breaks working programs, so it runs this fixed sample instead: files that
# pass on main, grouped by the language feature each one uses, so every
# producer a slice can touch has at least one whole program watching it.
#
# The floor is the number of these files that must pass. Every file here
# passes on main, so the floor is the length of the list: a branch that drops
# one has broken a working program, and the runner names the file.
#
# Blank lines and # comments are ignored, so this file is also a valid
# corpus.sh --only list. To refresh it, pick from a green main corpus run,
# keep the groups balanced, and move the floor in the same commit.
#
